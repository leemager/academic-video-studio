# Share your videos and back up your work

## Share a finished video

Ask Codex to export an MP4 and matching subtitles. Upload those to your usual teaching platform, research website or shared drive. Your audience only needs the finished files.

## Share this starter with a colleague

Send them [the repository link](https://github.com/leemager/academic-video-studio) and point them to **Start here** in the README. They can create a folder and ask Codex to download the starter, then set up their own voice and materials. No GitHub experience is needed.

The [download prompt](../GET-STARTED-FROM-GITHUB.txt) and [setup prompt](../STARTER-PROMPT.txt) are ready to copy and paste.

## Back up or move your studio

Your voice recordings, source material, generated narration and working videos are excluded from Git uploads by default. Ask Codex to make a backup containing those files and your editable projects. Store it in your usual private backup location.

To move to another computer, copy that backup and ask Codex to set up the tools there. Keep the selected narration files so your chosen readings stay exactly the same.

If you want to use GitHub for your own work, Codex can help create a separate private repository and choose what to include.
